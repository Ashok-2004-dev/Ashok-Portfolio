Featured · Desktop application

FindBack

Python · Tkinter

A desktop system that helps students and staff report, search and manage lost and found items on campus.

On a campus, lost belongings are hard to trace. Without one shared record, finders and owners rarely connect.

FindBack keeps every report in one application, so items can be recorded, searched and followed until they are returned.

  • Record an item's name, category, location, date, description and status
  • Search reported items
  • Manage and update records

It makes tracking and returning misplaced belongings easier for both students and staff.

Hackathon project · Healthcare

DrukHealth GO

GNH-based online hospital token system

An app idea that lets patients book a hospital token from their phone before leaving home, so they no longer queue from early morning just to get one. It was built for Bhutan's healthcare needs and the values of Gross National Happiness.

  • Online token booking by hospital and department, with an estimated waiting time
  • Live queue tracking, doctor schedule view and notification alerts
  • Emergency priority and an elderly priority queue
  • Dzongkha language option and a paperless, eco-friendly process

Tagline: "Healthcare should begin with care, not queues."
